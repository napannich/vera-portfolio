# Деплой на GitHub Pages (как serafima-portfolio)

1. github.com → New repository → имя **vera-portfolio** → Public → Create.
2. «uploading an existing file» → перетащить ВСЁ содержимое этой папки (не саму папку) → Commit.
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
4. Через 1–2 минуты сайт: **https://napannich.github.io/vera-portfolio/**

Эта ссылка уже прописана в PDF-резюме. Если назовёшь репозиторий иначе, ссылку в резюме надо поменять.

Обновление: загрузить изменённые файлы поверх (Add files → Upload files), Pages пересоберётся сам.
